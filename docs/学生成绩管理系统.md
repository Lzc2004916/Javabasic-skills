# 学生成绩管理系统

这是一个纯 Java 控制台案例，适合在学完 Java 基础语法、集合和文件 IO 后练习。项目不使用 Spring Boot，也不依赖第三方库。

## 一、完成后的功能

- 新增学生：学号、姓名、成绩
- 删除学生
- 修改学生成绩
- 按学号查询
- 按成绩从高到低查看全部学生
- 统计人数、平均分、最高分和最低分
- 使用 CSV 文件保存数据，程序启动时自动加载
- 对空输入、非法数字、重复学号、成绩越界进行处理

## 二、涉及的 Java 知识

| 功能 | 对应知识 |
| --- | --- |
| `Student` | 类、对象、封装、构造方法 |
| `Map<Integer, Student>` | 集合、键值查询 |
| 菜单循环 | `while`、`switch` |
| 输入校验 | 方法、循环、异常处理 |
| 成绩排序 | `List`、`Comparator`、方法引用 |
| 平均分统计 | 遍历、累计、条件判断 |
| 保存和加载 | `Path`、`Files`、字符流、CSV |

## 三、建议的实现顺序

不要一开始就试图记住全部代码，可以按下面的顺序理解：

1. 先阅读 `Student` 类，理解一个学生由哪些数据组成。
2. 阅读 `StudentService` 的 `add`、`findById`、`delete`，理解集合如何保存对象。
3. 阅读 `main` 方法和菜单，理解用户选择如何调用不同功能。
4. 阅读 `readPositiveInt`、`readScore`，理解 `try-catch` 和输入重试。
5. 阅读 `printAll` 和 `printStatistics`，理解排序与统计。
6. 最后阅读 `loadFromFile`、`saveToFile`，理解程序如何持久化数据。

## 四、完整代码

将下面代码保存为 `src/StudentScoreManager.java`。文件名必须和 `public class StudentScoreManager` 一致。

```java
import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.Scanner;

public class StudentScoreManager {
    private static final Path DATA_FILE = Paths.get("student_scores.csv");

    public static void main(String[] args) {
        StudentService service = new StudentService();
        service.loadFromFile(DATA_FILE);

        try (Scanner scanner = new Scanner(System.in)) {
            while (true) {
                printMenu();
                String choice = scanner.nextLine().trim();

                switch (choice) {
                    case "1": addStudent(scanner, service); break;
                    case "2": deleteStudent(scanner, service); break;
                    case "3": updateStudent(scanner, service); break;
                    case "4": findStudent(scanner, service); break;
                    case "5": service.printAll(); break;
                    case "6": service.printStatistics(); break;
                    case "7": service.saveToFile(DATA_FILE); break;
                    case "0":
                        service.saveToFile(DATA_FILE);
                        System.out.println("数据已保存，程序结束。");
                        return;
                    default: System.out.println("选项无效，请输入 0 到 7。");
                }
            }
        }
    }

    private static void printMenu() {
        System.out.println("\n===== 学生成绩管理系统 =====");
        System.out.println("1. 新增学生");
        System.out.println("2. 删除学生");
        System.out.println("3. 修改学生成绩");
        System.out.println("4. 按学号查询");
        System.out.println("5. 查看全部学生（按成绩降序）");
        System.out.println("6. 成绩统计");
        System.out.println("7. 手动保存");
        System.out.println("0. 保存并退出");
        System.out.print("请选择：");
    }

    private static void addStudent(Scanner scanner, StudentService service) {
        int id = readPositiveInt(scanner, "请输入学号：");
        if (service.contains(id)) {
            System.out.println("该学号已经存在。");
            return;
        }
        String name = readNonEmptyText(scanner, "请输入姓名：");
        double score = readScore(scanner, "请输入成绩（0-100）：");
        service.add(new Student(id, name, score));
        System.out.println("新增成功。");
    }

    private static void deleteStudent(Scanner scanner, StudentService service) {
        int id = readPositiveInt(scanner, "请输入要删除的学号：");
        Student removed = service.delete(id);
        System.out.println(removed == null ? "没有找到该学生。" : "删除成功：" + removed);
    }

    private static void updateStudent(Scanner scanner, StudentService service) {
        int id = readPositiveInt(scanner, "请输入要修改的学号：");
        Student student = service.findById(id);
        if (student == null) {
            System.out.println("没有找到该学生。");
            return;
        }
        double score = readScore(scanner, "请输入新成绩（0-100）：");
        student.setScore(score);
        System.out.println("修改成功：" + student);
    }

    private static void findStudent(Scanner scanner, StudentService service) {
        int id = readPositiveInt(scanner, "请输入要查询的学号：");
        Student student = service.findById(id);
        System.out.println(student == null ? "没有找到该学生。" : student);
    }

    private static int readPositiveInt(Scanner scanner, String prompt) {
        while (true) {
            System.out.print(prompt);
            String input = scanner.nextLine().trim();
            try {
                int value = Integer.parseInt(input);
                if (value > 0) return value;
            } catch (NumberFormatException ignored) {
                // 统一在循环末尾提示错误。
            }
            System.out.println("请输入大于 0 的整数。");
        }
    }

    private static double readScore(Scanner scanner, String prompt) {
        while (true) {
            System.out.print(prompt);
            String input = scanner.nextLine().trim();
            try {
                double value = Double.parseDouble(input);
                if (value >= 0 && value <= 100) return value;
            } catch (NumberFormatException ignored) {
                // 统一在循环末尾提示错误。
            }
            System.out.println("成绩必须是 0 到 100 之间的数字。");
        }
    }

    private static String readNonEmptyText(Scanner scanner, String prompt) {
        while (true) {
            System.out.print(prompt);
            String value = scanner.nextLine().trim();
            if (!value.isEmpty() && !value.contains(",")) return value;
            System.out.println("姓名不能为空，也不能包含英文逗号。");
        }
    }

    static class Student {
        private final int id;
        private final String name;
        private double score;

        Student(int id, String name, double score) {
            this.id = id;
            this.name = name;
            this.score = score;
        }

        int getId() { return id; }
        String getName() { return name; }
        double getScore() { return score; }
        void setScore(double score) { this.score = score; }

        @Override
        public String toString() {
            return String.format("学号：%d，姓名：%s，成绩：%.2f", id, name, score);
        }
    }

    static class StudentService {
        private final Map<Integer, Student> students = new LinkedHashMap<>();

        void add(Student student) { students.put(student.getId(), student); }
        boolean contains(int id) { return students.containsKey(id); }
        Student findById(int id) { return students.get(id); }
        Student delete(int id) { return students.remove(id); }

        void printAll() {
            if (students.isEmpty()) {
                System.out.println("暂无学生数据。");
                return;
            }
            List<Student> sorted = new ArrayList<>(students.values());
            sorted.sort(Comparator.comparingDouble(Student::getScore).reversed()
                    .thenComparingInt(Student::getId));
            System.out.println("\n--- 学生列表 ---");
            for (Student student : sorted) System.out.println(student);
        }

        void printStatistics() {
            if (students.isEmpty()) {
                System.out.println("暂无学生数据，无法统计。");
                return;
            }
            double total = 0;
            Student highest = null;
            Student lowest = null;
            for (Student student : students.values()) {
                total += student.getScore();
                if (highest == null || student.getScore() > highest.getScore()) highest = student;
                if (lowest == null || student.getScore() < lowest.getScore()) lowest = student;
            }
            System.out.printf("人数：%d%n平均分：%.2f%n最高分：%s%n最低分：%s%n",
                    students.size(), total / students.size(), highest, lowest);
        }

        void loadFromFile(Path path) {
            if (!Files.exists(path)) return;
            try (BufferedReader reader = Files.newBufferedReader(path, StandardCharsets.UTF_8)) {
                String line;
                int lineNumber = 0;
                while ((line = reader.readLine()) != null) {
                    lineNumber++;
                    if (lineNumber == 1 && line.equals("id,name,score")) continue;
                    String[] parts = line.split(",", -1);
                    if (parts.length != 3) continue;
                    try {
                        int id = Integer.parseInt(parts[0].trim());
                        String name = parts[1].trim();
                        double score = Double.parseDouble(parts[2].trim());
                        if (id > 0 && !name.isEmpty() && score >= 0 && score <= 100) {
                            add(new Student(id, name, score));
                        }
                    } catch (NumberFormatException ignored) {
                        // 忽略无法解析的数据行。
                    }
                }
            } catch (IOException e) {
                System.out.println("读取数据文件失败：" + e.getMessage());
            }
        }

        void saveToFile(Path path) {
            try (BufferedWriter writer = Files.newBufferedWriter(path, StandardCharsets.UTF_8)) {
                writer.write("id,name,score");
                writer.newLine();
                for (Student student : students.values()) {
                    writer.write(student.getId() + "," + student.getName() + "," + student.getScore());
                    writer.newLine();
                }
                System.out.println("数据已保存到：" + path.toAbsolutePath());
            } catch (IOException e) {
                System.out.println("保存数据文件失败：" + e.getMessage());
            }
        }
    }
}
```

## 五、编译和运行

在项目根目录 `D:\dispatcherServlet\StudySpringboot` 打开 PowerShell：

```powershell
javac -encoding UTF-8 -d out src\StudentScoreManager.java
java -cp out StudentScoreManager
```

这里的 `-encoding UTF-8` 是因为源码中包含中文。如果 IntelliJ IDEA 运行时出现中文乱码，请把项目和文件编码设置为 UTF-8。

## 六、建议测试流程

按下面顺序操作，可以覆盖主要功能：

1. 选择 `1`，新增 `1001`、`张三`、`88.5`。
2. 再新增 `1002`、`李四`、`95`。
3. 选择 `5`，确认李四排在张三前面。
4. 选择 `6`，确认人数为 2，平均分为 91.75。
5. 选择 `4` 查询 `1001`。
6. 选择 `3`，把 `1001` 修改为 `92`，再选择 `5` 查看排序变化。
7. 选择 `2` 删除 `1002`，再选择 `6` 查看统计变化。
8. 选择 `0` 退出，然后重新运行，确认数据仍然存在。
9. 输入 `abc`、`-1`、`101`，确认程序会提示并要求重新输入。

运行后，项目根目录会生成 `student_scores.csv`。这是程序的数据文件，不是 Java 源码。
