# 待办事项管理系统

这是第四个 Java 基础案例。它是一个纯 Java 控制台程序，用来练习集合、枚举、日期、排序、异常处理和文件持久化。

## 一、功能

- 新增待办事项
- 设置高、中、低优先级
- 设置截止日期，也可以不设置
- 完成待办
- 删除待办
- 查看全部待办
- 只查看未完成待办
- 按标题或描述关键词搜索
- 统计总数、未完成数和已完成数
- 使用 CSV 文件保存和加载数据

## 二、知识点对应关系

| 功能 | Java 知识 |
| --- | --- |
| `Task` | 类、对象、封装、构造方法 |
| `Priority`、`TaskStatus` | 枚举 `enum` |
| `Map<Integer, Task>` | 用编号快速查找任务 |
| `LocalDate` | 日期处理 |
| `Comparator` | 多条件排序 |
| `try-catch` | 输入和文件异常处理 |
| `BufferedReader/Writer` | 文件读取和写入 |

## 三、任务排序规则

查看任务时使用以下顺序：

1. 未完成任务排在已完成任务前面。
2. 优先级高的排在前面。
3. 优先级相同时，截止日期更早的排在前面。
4. 截止日期也相同时，编号更小的排在前面。

这段规则可以帮助你理解 `Comparator` 的多条件链式排序。

## 四、完整代码

将下面代码保存为 `src/TodoManager.java`。文件名必须与 `public class TodoManager` 一致。

```java
import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.time.LocalDate;
import java.time.format.DateTimeParseException;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Locale;
import java.util.Map;
import java.util.Scanner;

public class TodoManager {
    private static final Path DATA_FILE = Paths.get("todo_tasks.csv");

    public static void main(String[] args) {
        TodoService service = new TodoService();
        service.loadFromFile(DATA_FILE);

        try (Scanner scanner = new Scanner(System.in)) {
            while (true) {
                printMenu();
                String choice = scanner.nextLine().trim();
                try {
                    switch (choice) {
                        case "1": addTask(scanner, service); break;
                        case "2": completeTask(scanner, service); break;
                        case "3": deleteTask(scanner, service); break;
                        case "4": service.printTasks(service.sortedTasks()); break;
                        case "5": service.printTasks(service.pendingTasks()); break;
                        case "6": searchTasks(scanner, service); break;
                        case "7": service.printStatistics(); break;
                        case "8": service.saveToFile(DATA_FILE); break;
                        case "0":
                            service.saveToFile(DATA_FILE);
                            System.out.println("数据已保存，程序结束。");
                            return;
                        default: System.out.println("选项无效，请输入 0 到 8。");
                    }
                } catch (IllegalArgumentException | IllegalStateException e) {
                    System.out.println("操作失败：" + e.getMessage());
                }
            }
        }
    }

    private static void printMenu() {
        System.out.println("\n===== 待办事项管理系统 =====");
        System.out.println("1. 新增待办");
        System.out.println("2. 完成待办");
        System.out.println("3. 删除待办");
        System.out.println("4. 查看全部待办");
        System.out.println("5. 查看未完成待办");
        System.out.println("6. 按关键词搜索");
        System.out.println("7. 任务统计");
        System.out.println("8. 手动保存");
        System.out.println("0. 保存并退出");
        System.out.print("请选择：");
    }

    private static void addTask(Scanner scanner, TodoService service) {
        String title = readText(scanner, "请输入任务标题：");
        String description = readText(scanner, "请输入任务描述：");
        Priority priority = readPriority(scanner);
        LocalDate dueDate = readDueDate(scanner);
        Task task = service.add(title, description, priority, dueDate);
        System.out.println("新增成功：" + task);
    }

    private static void completeTask(Scanner scanner, TodoService service) {
        int id = readPositiveInt(scanner, "请输入要完成的任务编号：");
        service.complete(id);
        System.out.println("任务已完成。");
    }

    private static void deleteTask(Scanner scanner, TodoService service) {
        int id = readPositiveInt(scanner, "请输入要删除的任务编号：");
        service.delete(id);
        System.out.println("任务已删除。");
    }

    private static void searchTasks(Scanner scanner, TodoService service) {
        String keyword = readText(scanner, "请输入搜索关键词：");
        service.printTasks(service.search(keyword));
    }

    private static String readText(Scanner scanner, String prompt) {
        while (true) {
            System.out.print(prompt);
            String value = scanner.nextLine().trim();
            if (!value.isEmpty() && !value.contains(",")) return value;
            System.out.println("内容不能为空，也不能包含英文逗号。");
        }
    }

    private static int readPositiveInt(Scanner scanner, String prompt) {
        while (true) {
            System.out.print(prompt);
            try {
                int value = Integer.parseInt(scanner.nextLine().trim());
                if (value > 0) return value;
            } catch (NumberFormatException ignored) {
                // 在循环末尾统一提示错误。
            }
            System.out.println("请输入大于 0 的整数。");
        }
    }

    private static Priority readPriority(Scanner scanner) {
        while (true) {
            System.out.print("请输入优先级（1-高，2-中，3-低）：");
            switch (scanner.nextLine().trim()) {
                case "1": return Priority.HIGH;
                case "2": return Priority.MEDIUM;
                case "3": return Priority.LOW;
                default: System.out.println("请输入 1、2 或 3。");
            }
        }
    }

    private static LocalDate readDueDate(Scanner scanner) {
        while (true) {
            System.out.print("请输入截止日期（yyyy-MM-dd，直接回车表示无截止日期）：");
            String input = scanner.nextLine().trim();
            if (input.isEmpty()) return null;
            try {
                return LocalDate.parse(input);
            } catch (DateTimeParseException e) {
                System.out.println("日期格式错误，例如：2026-12-31。");
            }
        }
    }

    enum Priority {
        LOW(1, "低"), MEDIUM(2, "中"), HIGH(3, "高");
        private final int rank;
        private final String description;
        Priority(int rank, String description) { this.rank = rank; this.description = description; }
        int getRank() { return rank; }
        @Override public String toString() { return description; }
    }

    enum TaskStatus {
        PENDING("未完成"), DONE("已完成");
        private final String description;
        TaskStatus(String description) { this.description = description; }
        @Override public String toString() { return description; }
    }

    static class Task {
        private final int id;
        private final String title;
        private final String description;
        private final Priority priority;
        private final LocalDate dueDate;
        private TaskStatus status;

        Task(int id, String title, String description, Priority priority,
             LocalDate dueDate, TaskStatus status) {
            this.id = id; this.title = title; this.description = description;
            this.priority = priority; this.dueDate = dueDate; this.status = status;
        }

        int getId() { return id; }
        String getTitle() { return title; }
        String getDescription() { return description; }
        Priority getPriority() { return priority; }
        LocalDate getDueDate() { return dueDate; }
        TaskStatus getStatus() { return status; }
        void complete() { status = TaskStatus.DONE; }

        @Override
        public String toString() {
            String date = dueDate == null ? "无" : dueDate.toString();
            return String.format("编号：%d，标题：%s，描述：%s，优先级：%s，状态：%s，截止：%s",
                    id, title, description, priority, status, date);
        }
    }

    static class TodoService {
        private final Map<Integer, Task> tasks = new LinkedHashMap<>();
        private int nextId = 1;

        Task add(String title, String description, Priority priority, LocalDate dueDate) {
            Task task = new Task(nextId++, title, description, priority, dueDate, TaskStatus.PENDING);
            tasks.put(task.getId(), task);
            return task;
        }

        void complete(int id) {
            Task task = getTask(id);
            if (task.getStatus() == TaskStatus.DONE) throw new IllegalStateException("该任务已经完成。");
            task.complete();
        }

        void delete(int id) {
            if (tasks.remove(id) == null) throw new IllegalArgumentException("任务编号不存在。");
        }

        List<Task> sortedTasks() {
            List<Task> result = new ArrayList<>(tasks.values());
            result.sort(Comparator.comparing((Task task) -> task.getStatus() == TaskStatus.DONE)
                    .thenComparing(Comparator.comparingInt((Task task) -> task.getPriority().getRank()).reversed())
                    .thenComparing(task -> task.getDueDate(), Comparator.nullsLast(Comparator.naturalOrder()))
                    .thenComparingInt(Task::getId));
            return result;
        }

        List<Task> pendingTasks() {
            List<Task> result = new ArrayList<>();
            for (Task task : sortedTasks()) {
                if (task.getStatus() == TaskStatus.PENDING) result.add(task);
            }
            return result;
        }

        List<Task> search(String keyword) {
            String lowerKeyword = keyword.toLowerCase(Locale.ROOT);
            List<Task> result = new ArrayList<>();
            for (Task task : sortedTasks()) {
                if (task.getTitle().toLowerCase(Locale.ROOT).contains(lowerKeyword)
                        || task.getDescription().toLowerCase(Locale.ROOT).contains(lowerKeyword)) {
                    result.add(task);
                }
            }
            return result;
        }

        void printTasks(List<Task> taskList) {
            if (taskList.isEmpty()) {
                System.out.println("没有符合条件的任务。");
                return;
            }
            System.out.println("\n--- 任务列表 ---");
            for (Task task : taskList) System.out.println(task);
        }

        void printStatistics() {
            int pending = 0;
            int done = 0;
            for (Task task : tasks.values()) {
                if (task.getStatus() == TaskStatus.PENDING) pending++;
                else done++;
            }
            System.out.printf("任务总数：%d%n未完成：%d%n已完成：%d%n", tasks.size(), pending, done);
        }

        void loadFromFile(Path path) {
            if (!Files.exists(path)) return;
            try (BufferedReader reader = Files.newBufferedReader(path, StandardCharsets.UTF_8)) {
                String line;
                int lineNumber = 0;
                while ((line = reader.readLine()) != null) {
                    lineNumber++;
                    if (lineNumber == 1 && line.equals("id,title,description,priority,status,dueDate")) continue;
                    String[] parts = line.split(",", -1);
                    if (parts.length != 6) continue;
                    try {
                        int id = Integer.parseInt(parts[0].trim());
                        String title = parts[1].trim();
                        String description = parts[2].trim();
                        Priority priority = Priority.valueOf(parts[3].trim());
                        TaskStatus status = TaskStatus.valueOf(parts[4].trim());
                        LocalDate dueDate = parts[5].trim().isEmpty() ? null : LocalDate.parse(parts[5].trim());
                        if (id > 0 && !title.isEmpty() && !description.isEmpty()) {
                            tasks.put(id, new Task(id, title, description, priority, dueDate, status));
                            nextId = Math.max(nextId, id + 1);
                        }
                    } catch (IllegalArgumentException e) {
                        System.out.println("跳过格式错误的数据行：" + lineNumber);
                    }
                }
            } catch (IOException e) {
                System.out.println("读取数据文件失败：" + e.getMessage());
            }
        }

        void saveToFile(Path path) {
            try (BufferedWriter writer = Files.newBufferedWriter(path, StandardCharsets.UTF_8)) {
                writer.write("id,title,description,priority,status,dueDate");
                writer.newLine();
                for (Task task : tasks.values()) {
                    writer.write(task.getId() + "," + task.getTitle() + "," + task.getDescription()
                            + "," + task.getPriority().name() + "," + task.getStatus().name() + ","
                            + (task.getDueDate() == null ? "" : task.getDueDate()));
                    writer.newLine();
                }
                System.out.println("数据已保存到：" + path.toAbsolutePath());
            } catch (IOException e) {
                System.out.println("保存数据文件失败：" + e.getMessage());
            }
        }

        private Task getTask(int id) {
            Task task = tasks.get(id);
            if (task == null) throw new IllegalArgumentException("任务编号不存在。");
            return task;
        }
    }
}
```

## 五、编译和运行

在项目根目录打开 PowerShell：

```powershell
javac -encoding UTF-8 -d out src\TodoManager.java
java -cp out TodoManager
```

程序第一次运行时没有 `todo_tasks.csv` 也没关系。选择 `8` 手动保存，或选择 `0` 保存并退出，程序会自动创建它。

## 六、推荐测试流程

1. 选择 `1`，新增“学习 Java”“完成集合练习”，优先级高，截止日期 `2026-12-01`。
2. 再新增“整理笔记”“复习比较器”，优先级中，直接回车表示无截止日期。
3. 选择 `4`，观察未完成任务、优先级和截止日期排序。
4. 选择 `2`，输入任务编号 `1`，把第一项标记为已完成。
5. 选择 `5`，确认只显示未完成任务。
6. 选择 `6`，输入 `Java`，确认能搜索标题和描述。
7. 选择 `7`，确认统计结果。
8. 选择 `0` 退出，再次运行确认数据已经从 `todo_tasks.csv` 恢复。
9. 尝试输入不存在的编号、错误日期和重复完成任务，观察错误提示。
