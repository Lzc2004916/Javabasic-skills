# 图书借阅系统

这是第三个 Java 基础案例。它使用控制台菜单实现一个简单的图书借阅系统，不依赖 Spring Boot 或第三方库。

## 一、功能清单

- 新增图书
- 新增用户
- 借书
- 还书
- 查看全部图书及借阅状态
- 查看全部用户及已借图书
- 按书名关键词搜索图书
- 检查重复编号、无效编号、重复借阅、错误还书等情况

## 二、这个案例重点练什么

| 代码部分 | Java 知识 |
| --- | --- |
| `Book`、`User` | 类、对象、字段、构造方法、封装 |
| `BookStatus` | `enum` 枚举 |
| `Map<Integer, Book>` | 用键快速查找图书 |
| `Set<Integer>` | 保存用户借阅的图书编号，自动避免重复 |
| `LibraryService` | 把业务逻辑从菜单输入中分离出来 |
| `IllegalArgumentException` | 参数不合法时抛出异常 |
| `IllegalStateException` | 当前状态不允许操作时抛出异常 |
| `Comparator` | 按图书编号排序 |

## 三、业务关系

系统中有三个核心对象：

```text
User  ---- 借阅 ---->  Book
  |                    |
  |                    +-- status：可借 / 已借出
  +-- borrowedBookIds
```

借书时需要同时修改两处数据：

1. 把图书状态改成 `BORROWED`。
2. 把图书编号加入用户的 `borrowedBookIds`。

还书时反向修改：

1. 把图书状态改成 `AVAILABLE`。
2. 从用户的借阅集合中移除图书编号。

这就是为什么借书和还书被放在 `LibraryService` 中统一处理，而不是直接写在菜单代码里。

## 四、完整代码

将下面代码保存为 `src/LibraryBorrowingSystem.java`。文件名必须与 `public class LibraryBorrowingSystem` 一致。

```java
import java.util.ArrayList;
import java.util.Comparator;
import java.util.LinkedHashMap;
import java.util.LinkedHashSet;
import java.util.List;
import java.util.Map;
import java.util.Set;
import java.util.Scanner;

public class LibraryBorrowingSystem {
    public static void main(String[] args) {
        LibraryService library = new LibraryService();

        try (Scanner scanner = new Scanner(System.in)) {
            while (true) {
                printMenu();
                String choice = scanner.nextLine().trim();

                try {
                    switch (choice) {
                        case "1": addBook(scanner, library); break;
                        case "2": addUser(scanner, library); break;
                        case "3": borrowBook(scanner, library); break;
                        case "4": returnBook(scanner, library); break;
                        case "5": library.printBooks(); break;
                        case "6": library.printUsers(); break;
                        case "7": searchBooks(scanner, library); break;
                        case "0":
                            System.out.println("程序结束。");
                            return;
                        default: System.out.println("选项无效，请输入 0 到 7。");
                    }
                } catch (IllegalArgumentException | IllegalStateException e) {
                    System.out.println("操作失败：" + e.getMessage());
                }
            }
        }
    }

    private static void printMenu() {
        System.out.println("\n===== 图书借阅系统 =====");
        System.out.println("1. 新增图书");
        System.out.println("2. 新增用户");
        System.out.println("3. 借书");
        System.out.println("4. 还书");
        System.out.println("5. 查看全部图书");
        System.out.println("6. 查看全部用户及借阅情况");
        System.out.println("7. 按标题搜索图书");
        System.out.println("0. 退出");
        System.out.print("请选择：");
    }

    private static void addBook(Scanner scanner, LibraryService library) {
        int id = readPositiveInt(scanner, "请输入图书编号：");
        String title = readText(scanner, "请输入图书标题：");
        String author = readText(scanner, "请输入作者：");
        library.addBook(new Book(id, title, author));
        System.out.println("图书添加成功。");
    }

    private static void addUser(Scanner scanner, LibraryService library) {
        int id = readPositiveInt(scanner, "请输入用户编号：");
        String name = readText(scanner, "请输入用户姓名：");
        library.addUser(new User(id, name));
        System.out.println("用户添加成功。");
    }

    private static void borrowBook(Scanner scanner, LibraryService library) {
        int userId = readPositiveInt(scanner, "请输入用户编号：");
        int bookId = readPositiveInt(scanner, "请输入图书编号：");
        library.borrowBook(userId, bookId);
        System.out.println("借书成功。");
    }

    private static void returnBook(Scanner scanner, LibraryService library) {
        int userId = readPositiveInt(scanner, "请输入用户编号：");
        int bookId = readPositiveInt(scanner, "请输入图书编号：");
        library.returnBook(userId, bookId);
        System.out.println("还书成功。");
    }

    private static void searchBooks(Scanner scanner, LibraryService library) {
        String keyword = readText(scanner, "请输入标题关键词：");
        library.searchBooks(keyword);
    }

    private static int readPositiveInt(Scanner scanner, String prompt) {
        while (true) {
            System.out.print(prompt);
            try {
                int value = Integer.parseInt(scanner.nextLine().trim());
                if (value > 0) return value;
            } catch (NumberFormatException ignored) {
                // 在循环末尾统一提示。
            }
            System.out.println("请输入大于 0 的整数。");
        }
    }

    private static String readText(Scanner scanner, String prompt) {
        while (true) {
            System.out.print(prompt);
            String value = scanner.nextLine().trim();
            if (!value.isEmpty()) return value;
            System.out.println("内容不能为空。");
        }
    }

    enum BookStatus {
        AVAILABLE("可借"), BORROWED("已借出");

        private final String description;

        BookStatus(String description) { this.description = description; }

        @Override
        public String toString() { return description; }
    }

    static class Book {
        private final int id;
        private final String title;
        private final String author;
        private BookStatus status;
        private Integer borrowerId;

        Book(int id, String title, String author) {
            this.id = id;
            this.title = title;
            this.author = author;
            this.status = BookStatus.AVAILABLE;
        }

        int getId() { return id; }
        String getTitle() { return title; }
        BookStatus getStatus() { return status; }
        Integer getBorrowerId() { return borrowerId; }

        void borrowBy(int userId) {
            status = BookStatus.BORROWED;
            borrowerId = userId;
        }

        void returnBook() {
            status = BookStatus.AVAILABLE;
            borrowerId = null;
        }

        @Override
        public String toString() {
            String borrower = borrowerId == null ? "无" : String.valueOf(borrowerId);
            return String.format("编号：%d，书名：%s，作者：%s，状态：%s，借阅人：%s",
                    id, title, author, status, borrower);
        }
    }

    static class User {
        private final int id;
        private final String name;
        private final Set<Integer> borrowedBookIds = new LinkedHashSet<>();

        User(int id, String name) {
            this.id = id;
            this.name = name;
        }

        int getId() { return id; }
        Set<Integer> getBorrowedBookIds() { return borrowedBookIds; }

        @Override
        public String toString() {
            return String.format("编号：%d，姓名：%s，已借图书：%s",
                    id, name, borrowedBookIds.isEmpty() ? "无" : borrowedBookIds);
        }
    }

    static class LibraryService {
        private final Map<Integer, Book> books = new LinkedHashMap<>();
        private final Map<Integer, User> users = new LinkedHashMap<>();

        void addBook(Book book) {
            if (books.containsKey(book.getId()))
                throw new IllegalArgumentException("图书编号已经存在。");
            books.put(book.getId(), book);
        }

        void addUser(User user) {
            if (users.containsKey(user.getId()))
                throw new IllegalArgumentException("用户编号已经存在。");
            users.put(user.getId(), user);
        }

        void borrowBook(int userId, int bookId) {
            User user = getUser(userId);
            Book book = getBook(bookId);
            if (book.getStatus() == BookStatus.BORROWED)
                throw new IllegalStateException("这本书已经被借出，借阅人编号：" + book.getBorrowerId());
            book.borrowBy(userId);
            user.getBorrowedBookIds().add(bookId);
        }

        void returnBook(int userId, int bookId) {
            User user = getUser(userId);
            Book book = getBook(bookId);
            if (book.getStatus() == BookStatus.AVAILABLE)
                throw new IllegalStateException("这本书当前没有被借出。");
            if (!Integer.valueOf(userId).equals(book.getBorrowerId()))
                throw new IllegalStateException("这本书不是该用户借的，不能归还。");
            book.returnBook();
            user.getBorrowedBookIds().remove(bookId);
        }

        void printBooks() {
            if (books.isEmpty()) {
                System.out.println("暂无图书数据。");
                return;
            }
            List<Book> sortedBooks = new ArrayList<>(books.values());
            sortedBooks.sort(Comparator.comparingInt(Book::getId));
            System.out.println("\n--- 图书列表 ---");
            for (Book book : sortedBooks) System.out.println(book);
        }

        void printUsers() {
            if (users.isEmpty()) {
                System.out.println("暂无用户数据。");
                return;
            }
            System.out.println("\n--- 用户列表 ---");
            for (User user : users.values()) System.out.println(user);
        }

        void searchBooks(String keyword) {
            boolean found = false;
            System.out.println("\n--- 搜索结果 ---");
            for (Book book : books.values()) {
                if (book.getTitle().toLowerCase().contains(keyword.toLowerCase())) {
                    System.out.println(book);
                    found = true;
                }
            }
            if (!found) System.out.println("没有找到匹配的图书。");
        }

        private Book getBook(int bookId) {
            Book book = books.get(bookId);
            if (book == null) throw new IllegalArgumentException("图书编号不存在。");
            return book;
        }

        private User getUser(int userId) {
            User user = users.get(userId);
            if (user == null) throw new IllegalArgumentException("用户编号不存在。");
            return user;
        }
    }
}
```

## 五、编译和运行

在项目根目录打开 PowerShell：

```powershell
javac -encoding UTF-8 -d out src\LibraryBorrowingSystem.java
java -cp out LibraryBorrowingSystem
```

`-encoding UTF-8` 用于正确编译中文源码。

## 六、推荐测试流程

1. 选择 `1`，添加图书 `1001`、`Java编程思想`、`Bruce Eckel`。
2. 再选择 `1`，添加图书 `1002`、`Effective Java`、`Joshua Bloch`。
3. 选择 `2`，添加用户 `2001`、`张三`。
4. 选择 `3`，输入用户 `2001` 和图书 `1001`，确认借书成功。
5. 选择 `5`，确认 `1001` 状态为“已借出”。
6. 再次借阅 `1001`，确认程序拒绝重复借阅。
7. 选择 `4`，用用户 `2001` 归还 `1001`。
8. 用不存在的用户或图书编号操作，观察异常提示。
9. 选择 `7`，搜索关键词 `Java`。
10. 选择 `6`，查看用户的借阅记录。

## 七、建议你继续完成的升级

- 给用户增加最大借阅数量，例如最多借 3 本。
- 增加“删除图书”和“删除用户”，并限制已借出的图书不能删除。

- 为 `borrowBook` 和 `returnBook` 编写 JUnit 单元测试。
